# ボスは二度戦う

2人で同時に遊ぶ、2Dベルトスクロールアクションです。
画面を上下に分けて、それぞれが自分のステージでボスに挑み、**先にボスを倒したほうの勝ち**です。

## ゲームの特徴

- **上下2画面の同時対戦**：上が1P、下が2Pの画面です。お互いの進み具合を見ながら、同時にボスへ挑みます。
- **3つの形態を持つボス**：ボスはHPが減ると覚醒し、姿を消して先の地点へ移動します。追いかけて、また戦います。
- **相手への妨害**：自分のボスを覚醒させると、**相手のボスの攻撃力が上がります**。先に進むほど、相手を苦しめられます。
- **1人でも遊べる**：コントローラーをつながずに起動すると、キーボードで1画面の1人用として遊べます。

## ルール

1. 「3・2・1・GO!」の合図でスタートします。
2. 右へ進むと、ボスとの戦闘が始まります。
3. ボスのHPを減らすと覚醒して姿を消すので、先へ進んで再び戦います。覚醒は2回あります。
4. **先にボスを倒したプレイヤーの勝ち**です。自分がやられた場合は、相手の勝ちになります。

## 操作方法

| 操作 | キーボード | ゲームパッド |
|---|---|---|
| 移動 | W / A / S / D | 左スティック |
| ジャンプ | Space | 下ボタン（Xbox：A、PlayStation：×） |
| 攻撃 | Enter | 右トリガー |
| ポーズ | Esc | Startボタン |
| メニューの選択 | 矢印キー / WASD | 十字キー / 左スティック |
| メニューの決定 | Enter | 下ボタン（Xbox：A、PlayStation：×） |

- 2人で遊ぶときは、**ゲームパッドを2台**つないでから起動してください。ゲームパッドが1台のときは、ゲームパッドが1P、キーボードが2Pになります。
- タイトル画面の「遊び方」で、遊び方を確認できます。
- ゲーム中にやめるときは、ポーズメニューから「タイトルへ戻る」「ゲームを終了」を選べます。

## 起動方法（Unityで開く場合）

1. Unity **6000.3.10f1** でこのプロジェクトを開きます。
2. `Assets/Scenes/title.unity` を開いて再生します。

ビルド設定では、`title` → `GameScene`（バトル）の順に読み込まれます。

### 配布用のビルドを作る

Unity のメニューから **「配布」→「配布用ビルドを作成」** を選ぶと、Windows 64bit 版をビルドし、
遊び方（`README.txt`）とライセンス文書を同梱した `Build/TheBossReturns_v1.0_Windows.zip` を作成します。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `Assets/TaTsuya/` | ボス、バトル進行、2画面（ステージ管理）、タイトル、UIなど |
| `Assets/Kaneda/` | プレイヤー（移動・攻撃・入力）、影 |
| `Assets/BaseScript/` | キャラクターの共通処理、ステートマシン、オブジェクトプールなど |
| `Assets/2DAsset/` | 外部の2D素材（下の「使用素材」を参照） |
| `Assets/Nova/` | エフェクト用シェーダー（外部ライブラリ） |

### 主なスクリプト

| スクリプト | 役割 |
|---|---|
| `BattleManager` | ステージとカメラの生成、開始のカウントダウン、勝敗の判定、妨害の受け渡し |
| `StageContext` | 1人分のステージ（カメラ・プレイヤー・ボス・HPバー・戦闘中かどうか）の管理 |
| `BossBehaviorManager` | ボスの行動（待機・攻撃の抽選・覚醒）のステートマシン |
| `BossAttackManager` | ボスの攻撃（召喚・連射・瞬間移動からの近接攻撃）と効果音 |
| `BossBulletManager` | ボスが出す弾・エフェクトの動きと当たり判定 |
| `TatuGameManager` | HPバー、結果画面、ポーズメニューなどのUI |
| `TitleManager` | タイトル画面とチュートリアルのページ送り |
| `UiSelectionKeeper` | コントローラー・キーボードでのボタン操作（表示中のボタンを自動で選択） |
| `CanvasScaleSetting` | 解像度が違ってもUIが崩れないようにする設定 |
| `DistributionBuilder` | 配布用ビルドの作成（エディタ拡張） |
