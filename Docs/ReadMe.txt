■ ゲームの起動方法
--------------------------------------------------
1. TheBossReturns_v1.0_Windows.zip を展開します。
2. 展開したフォルダの TheBossReturns.exe を実行します。

※ 2人で遊ぶときは、起動する前にゲームパッドを2台つないでください。
  ゲームパッド1台のときは、ゲームパッドが1P、キーボードが2Pになります。
  1人で遊ぶときは、ゲームパッドをつながずに起動してください(キーボードで遊べます)。
※ 操作方法の詳細は、ZIPの中の README.txt に書いてあります。


■ 主な操作
--------------------------------------------------
              キーボード             ゲームパッド
  移動        W / A / S / D         左スティック
  ジャンプ    Space                 下ボタン(Xbox:A / PS:×)
  攻撃        Enter                 右トリガー
  ポーズ      Esc                   Startボタン

ゲームを終了するときは、タイトル画面の「終わる」、
またはポーズメニューの「ゲームを終了」を選んでください。

■ プロジェクトについて
--------------------------------------------------
・Unity 6000.3.10f1 で開いてください。
・Assets/Scenes/title.unity から再生すると、タイトルから遊べます。
　(バトルは Assets/Scenes/GameScene.unity)
・自身が作成したスクリプトは主に Assets/TaTsuya/Script/ と
　Assets/BaseScript/ にあります。詳しくは作品概要.txt の「3」を見てください。

【素材を除いている理由】
キャラクター(Bringer Of Death、Warrior free set)と背景(Dark Forest)の素材は、
ライセンスで再配布が禁止されているため、プロジェクトからは除いています。
そのため、プロジェクトを開くとキャラクターと背景の画像が表示されませんが、
スクリプトのコンパイルやシーンの構成は確認できます。
実際の動作は、ゲーム本体(TheBossReturns_v1.0_Windows.zip)でご確認ください。
