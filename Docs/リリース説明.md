2人で同時に遊ぶ、2Dベルトスクロールアクションです。画面を上下に分けてそれぞれのボスに挑み、先に倒したほうの勝ちです。自分のボスを覚醒させると、相手のボスの攻撃力が上がります。

## 遊び方

1. 下の Assets から `TheBossReturns_v1.0_Windows.zip` をダウンロードします
2. zip を展開します
3. フォルダの中の `TheBossReturns.exe` をダブルクリックします

※ フォルダの中身（`TheBossReturns_Data`、`UnityPlayer.dll` など）は、exe と同じ場所に置いたまま起動してください。
※ Windows の「PC が保護されました」という画面が出た場合は、「詳細情報」→「実行」を押してください。
※ 終了はタイトル画面の「終わる」、またはポーズメニューの「ゲームを終了」から行えます。

## 動作環境

- Windows 10 / 11（64bit）
- DirectX 11 以上に対応した GPU
- キーボード、またはコントローラー（PS4 / PS5 / Xbox）

動作確認済み：raytrek（Intel Core i7 / NVIDIA GeForce RTX）

## 操作方法

| 操作 | キーボード | コントローラー（PS / Xbox） |
|---|---|---|
| 移動 | W / A / S / D | 左スティック |
| ジャンプ | Space | × / A |
| 攻撃 | Enter | R2 / RT |
| ポーズ | Esc | OPTIONS / メニュー |
| メニューの選択 | 矢印キー / W / A / S / D | 十字キー / 左スティック |
| メニューの決定 | Enter | × / A |

## プレイ人数

- コントローラー2台：1P と 2P で遊べます
- コントローラー1台＋キーボード：コントローラーが 1P、キーボードが 2P になります
- キーボードのみ：1人用（1画面）で遊べます
- コントローラーは、起動する前に PC につないでください
