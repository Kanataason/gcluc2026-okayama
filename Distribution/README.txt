==================================================
  ボスは二度戦う
==================================================

2人で同時に遊ぶ、2Dベルトスクロールアクションです。
画面を上下に分けて、それぞれが自分のステージでボスに挑み、
先にボスを倒したほうの勝ちです。


■ 起動方法
--------------------------------------------------
1. ZIPファイルを好きな場所に展開してください。
2. 「BossWaNidoTatakau.exe」をダブルクリックすると始まります。

※ 2人で遊ぶときは、起動する前にゲームパッドを2台
  (またはゲームパッド1台とキーボード)をつないでください。
  ゲームパッドが1台だけのときは、1人用として遊べます。


■ ルール
--------------------------------------------------
・「3・2・1・GO!」の合図でスタートします。
・右へ進むと、ボスとの戦闘が始まります。
・ボスのHPを減らすと覚醒して姿を消すので、先へ進んで再び戦います。
・自分のボスを覚醒させると、相手のボスの攻撃力が上がります。
・先にボスを倒したプレイヤーの勝ちです。
  自分がやられた場合は、相手の勝ちになります。


■ 操作方法
--------------------------------------------------
              キーボード             ゲームパッド
  移動        W / A / S / D         左スティック
  ジャンプ    Space                 下ボタン(Xbox:A / PS:×)
  攻撃        Enter / 左クリック     右トリガー
  ポーズ      Esc                   Startボタン

  メニューの操作
  ボタン選択  矢印キー / WASD        十字キー / 左スティック
  決定        Enter                 下ボタン(Xbox:A / PS:×)


■ 終了方法
--------------------------------------------------
・タイトル画面の「終わる」を選びます。
・ゲーム中は、ポーズ(Esc / Startボタン)から「ゲームを終了」を選びます。


■ 動作環境
--------------------------------------------------

・画面サイズ 1920×1080 推奨
